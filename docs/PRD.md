# Product Requirement Document (PRD)
## EcoResearch AI: Sustainability & Policy Analysis Workspace

---

## 1. Executive Summary & Vision

**EcoResearch AI** is an enterprise-grade, AI-powered research assistant and report generator specifically engineered for Sustainability Research Analysts and Policy Advisors. 

In the sustainability sector, advisors must digest, cross-reference, and synthesize anywhere from **20 to 50+ dense textual resources** (such as IPCC climate reports, UN Sustainable Development Goals guidelines, national regulatory frameworks, and peer-reviewed environmental studies) for a single policy brief or compliance report.

EcoResearch AI solves this information overload by providing:
- High-capacity multi-document ingestion and semantic vector index management.
- **Universal Strict Citation Enforcement**: Every output generated by the AI (chat responses, policy summaries, outline items, report sections) MUST include precise, fine-grained, verifiable citations back to the source document, page number, and exact text snippet.
- Autonomous, multi-agent report generation powered by **LangGraph**, structuring complex multi-section policy documents based on analyst-defined criteria.
- State-persisted multi-session memory backed by a **SQL Database**.
- High-performance LLM inference leveraging **NVIDIA API Endpoints**.
- A dusk-lit, frosted-glass UI workspace adhering to the **Dimension Design System**.

---

## 2. Target User Personas

### Persona 1: Senior Policy Advisor (Government & NGO Sector)
- **Goal**: Draft comprehensive policy briefing papers based on dozens of international climate benchmarks and national regulations.
- **Pain Point**: Spending 60% of work time manually reading and comparing policy clauses across multiple PDF documents, risking missed regulatory nuances or inaccurate cross-referencing.
- **Key Need**: Instant cross-document synthesis, **100% verifiable citations for every claim**, exportable structured policy reports.

### Persona 2: ESG & Sustainability Research Analyst (Corporate & Consulting)
- **Goal**: Evaluate company supply chains against 30+ ESG framework papers (GRI, SASB, TCFD, EU CSRD).
- **Pain Point**: Managing massive document sets per client engagement and building audit-proof reports under strict deadlines.
- **Key Need**: Batch upload of 20–50 documents, custom outline generation, precise Q&A against client document vaults with **mandatory snippet-level citations**, long-term project session memory.

## 3. Key Feature Specifications & User Stories

### Feature Module 1: Document Vault & Ingestion Pipeline
- **User Story**: *As a research analyst, I want to upload a batch of 20 to 50+ PDF research papers so that they are indexed with detailed page and paragraph location markers for fine-grained citations.*
- **Requirements**:
  - Drag-and-drop batch upload supporting up to 50+ files (PDF, DOCX, TXT, Markdown).
  - Background asynchronous chunking (Semantic & Hierarchical chunking tailored for academic/policy formats).
  - Metadata Extraction & Tagging: Auto-detect title, author, year, document scope, page boundaries, and section headers.
  - Document status indicator (Uploading -> Extracting -> Indexing -> Ready).

### Feature Module 2: Cross-Document Interactive Q&A with Mandatory Citations
- **User Story**: *As a policy advisor, I want every single answer from the AI to be anchored by inline citations so I can trace every fact back to its exact source.*
- **Requirements**:
  - Natural language chat interface with conversational context memory.
  - **Universal Citation Requirement**: 100% of LLM-generated assertions must contain inline citation tags `[Doc X, p. Y, § Z]`.
  - Citation Cards: Hoverable/clickable inline citations referencing specific document name, page number, paragraph index, and verbatim source quote snippet.
  - Query Filters: Ability to scope Q&A to selected subset of uploaded documents.

### Feature Module 3: LangGraph Autonomous Report Generator with Citation Audit
- **User Story**: *As an analyst, I want an auto-generated structured 10-page sustainability report where every paragraph, statistic, and recommendation is cited back to my uploaded papers.*
- **Requirements**:
  - **Phase 1: Outline Creation**: AI proposes a multi-section report outline with source document mapping.
  - **Phase 2: Parallel Deep Research**: LangGraph sub-agents search vector stores for section-specific evidence and synthesize draft text.
  - **Phase 3: Automated Citation Audit & Verification**: A specialized `CitationVerifier` agent cross-checks every sentence against source texts, injects standard inline citations `[Doc X, p. Y]`, and strips any uncited hallucinated statements.
  - **Phase 4: Synthesis & Formatting**: Assembles the complete document with an automatically generated **References & Source Citations Appendix**, renders Markdown preview, and exports to PDF / DOCX.

### Feature Module 4: SQL Persistent Session Memory
- **User Story**: *As an analyst working on a multi-week project, I want my chats, uploaded document metadata, custom outlines, generated reports, and verified citations saved persistently so I can pick up where I left off.*
- **Requirements**:
  - Project/Session workspace management.
  - LangGraph Postgres/SQL Checkpointer to persist agent state, execution steps, verified citations, and memory threads.
  - History view showing past Q&A turns, uploaded files, and generated report revisions.

### Feature Module 5: NVIDIA NIM Model Engine Integration
- **User Story**: *As a system administrator, I want all LLM calls routed exclusively through NVIDIA API endpoints for high-performance inference.*
- **Requirements**:
  - Model Provider: `langchain-nvidia-ai-endpoints`.
  - Supported Models: `meta/llama-3.1-70b-instruct`, `mistralai/mixtral-8x22b-instruct`, `nvidia/embed-qa-4` for vector embeddings.
  - Configurable system prompts with strict grounding & citation instructions (e.g. system prompt forces model to decline answering if no direct source chunk is found).

---

## 4. Non-Functional Requirements

- **Citation Verifiability**: 100% citation coverage on all generated output; zero uncited factual claims permitted.
- **Performance**: Document indexing for 50 PDFs (1000 total pages) completed within 2–3 minutes; RAG query responses returned in under 4 seconds.
- **Reliability & Resilience**: LangGraph state checkpointing guarantees no work loss if a long report generation process is interrupted.
- **Scalability**: Decoupled Next.js frontend (Vercel) and Python FastAPI server (Render) with scalable PostgreSQL vector storage (pgvector).
- **Usability**: Adherence to the **Dimension Design System** (dusk-lit dark aesthetic, frosted glass panels, pill buttons, DM Sans/Geist typography).

---

## 5. Success Metrics

1. **100% Citation Precision**: Zero unverified or uncited claims in generated reports and Q&A answers.
2. **Time Saved**: Reduce report compilation time from 15 hours to under 30 minutes for a 30-document synthesis task.
3. **User Engagement**: Analysts actively managing 5+ distinct document vaults with persistent historical continuity.
